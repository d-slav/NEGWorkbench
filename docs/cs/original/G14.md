# PŘÍKAZY TRANSFORMAČNÍ

## PŘÍKAZY K DEFINOVÁNÍ SOUŘADNICOVÝCH SOUSTAV

### Definování rovinné souřadnicové soustavy

#### `DCOOS`
Tvar příkazu:
```
	DCOOS,vi,vg1,vg2

```

- **vi** — <M>celočíselný výraz, jehož hodnota nesmí překročit interval <<1,5>>. Představuje identifikační číslo přiřazené definované soustavě.
- **vg1** — geometrický výraz typu P - bod, který udává počátek definované soustavy v souřadnicích základní soustavy.
- **vg2** — geometrický výraz typu P, V, L, D, A, který udává kladný směr osy x' nové definované souřadnicové soustavy. Interpretace povolených typů objektů:
  - **P** — kladný směr osy x' prochází bodem vg2,
  - **V** — kladný směr osy x' je totožný se směrem vektoru vg2,
  - **L** — kladný směr osy x' je totožný s kladným směrem přímky vg2,
  - **D, A** — kladný směr osy x' svírá s kladným směrem osy x základní soustavy úhel vg2.
Příklad 1.:
```
	DCOOS,3,P5,PX

```

Je definována souřadnicová soustava číslo 3. Její počátek leží v bodu P5 a kladný směr x' prochází bodem PX.
Příklad 2.:
```
	DCOOS,1,(P00>>100,50),45

```

Je definována souřadnicová soustava číslo 1. Její počátek leží v bodu o souřadnicích x=100, y=50 a kladný směr osy x' svírá s kladným směrem osy x základní soustavy úhel 45 stupňů.

### Definování prostorové souřadnicové soustavy

#### `DCOOS3`
Tvar příkazu:
```
	DCOOS3,vi,vg1,vg2,vg3

```

- **vi** — celočíselný výraz, jehož hodnota nesmí překročit interval <<1,10>>. Představuje identifikační číslo přiřazené definované soustavě.
- **vg1** — geometrický výraz typu Q - bod, který udává počátek definované soustavy v souřadnicích základní soustavy.
- **vg2** — geometrický výraz typu Q,U,M, který udává kladný směr osy x' nové definované soustavy. Interpretace povolených typů objektů:
  - **Q** — kladná osa x' prochází bodem vg2,
  - **U** — kladný směr osy x' je totožný se směrem vektoru vg2,
  - **M** — kladný směr osy x' je totožný s kladným směrem přímky vg2.
- **vg3** — geometrický výraz typu Q,U,M, který určuje směr a orientaci osy y'. Interpretace povolených typů.
  - **Q** — osa y' leží v rovině určené osou x' a bodem vg3. Kladný směr osy y' směřuje do poloroviny v níž leží bod vg3.
  - **U** — osa y' leží v rovině určené osou x' a vektorem vg3. Kladný směr osy y'leží v polorovině, do které směruje vektor vg3.
  - **M** — osa y' leží v rovině, v níž leží osa x' a která je rovnoběžná s přímkou vg3. Kladný směr osy y' leží v polorovině, do níž směřuje kladný směr přímky vg3.
```

```

Příklad 1.:
```
	DCOOS3,3,Q5,UX,UY

```

Je definována souřadnicová soustava číslo 3. Její počátek leží v bodu Q5 a kladný směr osy x' je určen vektorem UX. Rovina X'Y' je určená bodem Q5 a vektory UX a UY. Osa y' je kolmá k ose x' a jeji kladný směr míří do poloroviny, do které směřuje vektor UY.
Příklad 2.:
```
	DCOOS3,8,(Q00>>0,0,0),(U00>>1,1,1),QCC

```

Je definována souřadnicová soustava číslo 8. Její počátek leží v počátku soustavy základní (bod 0,0,0) a kladný směr osy x' je určen vektorem 1,1,1. Rovina X'Y' je daná osou x' a bodem QCC. Osa y' je kolmá k ose x' a její kladný směr míří do poloroviny, v níž leží bod QCC.

### Definování souřadnicové soustavy v dané rovině

#### `PLANE`
Tvar příkazu:
```
	PLANE,vi,vg1[,[vg2][,vt]]

```

- **vi** — celočíselný výraz, jehož hodnota nesmí překročit interval <<1,10>>. Představuje identifikační číslo přiřazené definované soustavě.
- **vg1** — geometrický výraz typu R - rovina, v níž bude souřadnicová soustava definována.
- **vg2** — geometrický výraz typu Q, M - objekt, který definuje počátek nové souřadnicové soustavy. Interpretace dovolených typů objektů:
  - **Q** — počátek souřadnicové soustavy je v patním bodu kolmice spuštěné z bodu vg2 na rovinu vg1,
  - **M** — počátek souřadnicové soustavy je v průsečíku přímky vg2 s rovinou vg1.
```
Tento parametr je nepovinný. Není-li uveden, je dosazen default dle odst. 9.5.3.2.
```

- **vt** — výběrové slovo transformace určující směr a smysl os x' a y' nové souřadnicové soustavy. Určení výběrového slova - viz odst. 9.5.3.3. Rovněž tento parametr je nepovinný. Není-li uveden, je dosazen default dle odst. 9.5.3.4.
```

```

Příklad 1.:
```
	PLANE,6,REZ,MPC,'ZXIL'

```

Je definována souřadnicová soustava číslo 6. Její rovina X'Y' leží v rovině REZ. Počátek této soustavy leží v průsečíku přímky MPC s rovinou REZ. Směr a smysl os x' a y' je určen výběrovým slovem ZXIL.
Příklad 2.:
```
	PLANE,(R08>>QC1,QC2,(Q00>>10,0,0))

```

Je definována souřadnicová soustava číslo 1. Její rovina X'Y' je určená body QC1, QC2 a bodem 10,0,0. Parametry pro počátek soustavy a směr a smysl jejich os nejsou uvedeny - jsou dosazeny default hodnoty.

### Invertování rovinné souřadnicové soustavy

#### `INVER`
Tvar příkazu:
```
	INVER,vi1,vi2

```

- **vi1** — celočíselný výraz, jehož hodnota nesmí překročit interval <<1,5>>. Představuje identifikační číslo soustavy, která má být invertována.
- **vi2** — celočíselný výraz nabývající hodnoty 0 nebo 1. Slouží jako kontrolní parametr. Povinná nastavení:
  - **0** — při první (obecně liché) inverzi dané soustavy v rámci jednoho programu (vlastní invertování).
  - **1** — při druhé (obecně sudé) inverzi dané soustavy v rámci jednoho programu (návrat zpět do původního stavu).
```
Není-li kontrolní parametr nastaven podle těchto pravidel, je hlášena chyba (viz odst. 9.6).
```

## AKTIVACE VSTUP/VÝSTUPNÍCH TRANSFORMACÍ

### Aktivace vstup/výstupních transformací v rovině

#### `COOS`
Tvar příkazu:
```
	COOS,vi

```

- **vi** — celočíselný výraz, jehož hodnota nesmí překročit interval <<0,5>>. Výraz vi představuje číslo aktivované souřadnicové soustavy. (vi=0 ruší aktivitu dříve aktivované soustavy).
```

```

Příklad 1.:
```
	COOS,3

```

Po provedení příkazu je aktivována rovinná souřadnicová soustava 3, dříve definovaná příkazem DCOOS. Při provádění vstup/výstupních operací s rovinnými objekty probíhá automaticky transformace z/do aktivované soustavy. Tento stav trvá až do provedení dalšího příkazu COOS.
Příklad 2.:
```
	COOS,0

```

Příkaz ruší transformační aktivitu do toho okamžiku aktivní soustavy. Po provedení příkazu probíhají rovinné vstup/výstupní operace bez transformace.

#### `COOS3`

- **vi** — celočíselný výraz, jehož hodnota nesmí překročit interval <<0,10>>. Výraz vi představuje číslo aktivované prostorové souřadnicové soustavy. (vi=0 ruší aktivitu dříve aktivované soustavy).
```

```

Příklad 1.:


Po provedení příkazu je aktivována prostorová souřadnicová soustava 5, dříve definovaná příkazem DCOOS3 (nebo PLANE). Při provádění vstup/výstupních operací s prostorovými objekty probíhá automaticky transformace z/do aktivované soustavy. Tento stav trvá až do provedení dalšího příkazu COOS3.
Příklad 2.:
```
	COOS3,0

```

Příkaz ruší transformační aktivitu do toho okamžiku aktivní soustavy. Po provedení příkazu probíhají prostorové vstup/výstupní operace bez transformace.

## PŘÍKAZY PRO TRANSFORMACI MEZI PROSTOREM A ROVINOU

### Transformace z prostoru do roviny

#### `TRA32`
Tvar příkazu:
```
	TRA32,pg1,pg2,vi1,vi2

```

- **pg1** — identifikátor rovinné geometrické proměnné, který označuje počáteční prvek množiny objektů, které mají vzniknout jako výsledek transformace. (Výstupní objekty).
- **pg2** — identifikátor prostorové geometrické proměnné, který označuje počáteční prvek množiny objektů, které mají být transformovány. (Vstupní objekty).
- **vi1** — celočíselný výraz, jehož hodnota určuje počet objektů, které budou příkazem transformovány.
- **vi2** — celočíselný výraz, jehož hodnota představuje identifikační číslo souřadnicové soustavy definované příkazem PLANE nebo DCOOS3.
Typy výstupní a vstupní geometrické proměnné jsou vzájemně závislé a musí odpovídat tabulce:
```
	Výstupní objekt 		Vstupní objekt
	P		Q
	V		U
	L		M
	C		G
	E		H
	S		T

```

Podrobnější popis použití příkazu je uveden v odst. 9.5.
