# NEGEOMETRICKÉ OPERACE

## ARITMETICKÉ PŘÍKAZY

Jazyk GL-3 zajišťuje možnost aritmetických výpočtů a to buď celočíselných nebo racionálních, které se provádějí pomocí aritmetických příkazů daného typu.
Tvar celočíselného aritmetického příkazu:
```
	pi=vi
```

kde pi je celočíselná proměnná (nesmí být výraz ani konstanta) a vi je celočíselný aritmetický výraz - viz odst. 3.2 a 3.6.
Tvar racionálního aritmetického příkazu:
```
	pg(D)=vr
```

kde pg(D) je racionální proměnná typu A nebo D a vr je racionální aritmetický výraz - viz odst. 3.2 a 3.6.
V aritmetickém příkazu (celočíselném nebo racionálním) se nejprve vyhodnotí hodnota aritmetického výrazu vi nebo vr na pravé straně a tato hodnota se přiřadí proměnné pi nebo pg na levé straně příkazu.
Příklady:
a) celočíselné aritmetické výrazy:
```
	I1=3*(5-J)/(28+IJ)
	I2=1
	I3=I2*I1

```

b) racionální aritmetické výrazy:
```
	A1A3=(A10-A30)/2.*(3.14*A13)
	DD=4.12
	DA=D+A<< 	(je povolená kombinace objektů typu A a D
			v jednom aritmetickém výrazu)
	AX3=((AX*3.)-(5.*DX*DXX-2.))*A3
```

## MATEMATICKÉ FUNKCE

Jazyk GL-3 umožňuje definovat celočíselnou nebo racionální proměnnou pomocí různých matematických funkcí.

### Goniometrické, logaritmické a exponenciální funkce

Při označení z odst. 3.2 je tvar příkazu:
```
	pg(D)=FUNKCE>>vr
```

- **pg(D)** — výsledek (geometrická proměnná typu D nebo A),
- **FUNKCE** — funkční operátor, který může být následujících typů:
  - **SIN** — sinus úhlu
  - **COS** — cosinus úhlu
  - **TAN** — tangens úhlu
  - **ASIN** — arcussinus úhlu
  - **ACOS** — arcuscosinus úhlu
  - **ATAN** — arcustangens úhlu
  - **LN** — přirozený logaritmus argumentu
  - **LOG** — dekadický logaritmus argumentu
  - **EXP** — exponenciální hodnota argumentu
- **vr** — definuje hodnotu argumentu goniometrické, logaritmické nebo exponenciální funkce.

Hodnota argumentu pro funkce SIN, COS a TAN a hodnota výsledku pro funkce ASIN, ACOS, ATAN se vyjadřuje v úhlových stupních. Pro hodnoty argumentů všech funkcí platí omezení vyplývající z matematické podstaty zadané funkce:

- **SIN, COS, ATAN** — bez omezení,
- **EX** — bez omezení,
- **ASIN, ACOS** — argument z intervalu <<-1;1>>
- **TAN** — argument pro všechna čísla s výjimkou lichých násobků 90 stupňů,
- **LN, LOG** — kladný argument.

Příklady:
```
	DX=SIN>>(2.*A10)
	DY=COS>>((5.-DX)/AY)
	DA=TAN>>35.
	AX=ATAN>>(35.-DA)
	AY=ACOS>>-0.003
	DD=ASIN>>(1./(DX+DY-AY))
	DX=TAN>>(D13>>(P20>>L1,L2),S3T,(5*I-3))
	D10=EX>>(2.*DPI)
	DLN=LN>>10.56778
	DLOG=LOG>>(D89>>TQS)

```

### Výpočet absolutní hodnoty (ABS)

#### `ABS`
Funkce ABS počítá absolutní hodnoty racionálního čísla.
Tvar příkazu:
```
	pg(D)=ABS>>vr
```

### Výpočet druhé odmocniny (SQRT)

#### `SQRT`
Funkce SQRT počítá druhou odmocninu racionálního čísla.
Tvar příkazu:
```
	pg(D)=SQRT>>vr
```

Omezení: argument vr>>=0

### Funkce pro převody mezi racionálními a celými čísly (FLOAT, INI, AINT)

#### `FLOAT`
Funkce FLOAT převádí celé číslo na racionální.
Tvar příkazu:
pg(D)=FLOAT>>vi
#### `INT`
Funkce INT převádí racionální číslo na celé číslo.
Tvar příkazu:
pi=INT>>vr
#### `AINT`
Funkce AINT odřezává desetinnou část racionálního čísla.
Tvar příkazu:
pg(D)=AINT>>vr
Příklady:
```
	AX=FLOAT>>100		<<.....v proměnné AX je uloženo 100.
	INTE=INT>>3.9987	<<.. -"- INTE -"- 3
	DX=AINT>>3.9987		<<... -"- DX -"- 3.
```

## ORGANIZAČNÍ NEGEOMETRICKÉ OPERACE

Operace uvedené v tomto odstavci mají charakter funkcí. Výsledek činnosti je ukládán do celočíselné proměnné pi.

### Vyšetřování délky textu (NTEX)

#### `NTEX`
Funkce NTEX zjišťuje skutečný počet znaků uložených v textové proměnné nebo konstantě vt.
Tvar příkazu:
pi=NTEX>>vt

### Informace o složených objektech (NPO,NSE)

#### `NPO`
Funkce NPO zjišťuje pro složený objekt typu S, E, H, T (křivky a řetězce) počet uzlových bodů, z nichž se daný složený objekt skládá.
Tvar příkazu:
pi=NPO>>vg(S, E, T, H)
#### `NSE`
Funkce NSE pro rovinné i prostorové křivky i řetězce zjišťuje počet segmentů resp. úseček, z nichž se křivka nebo řetězec skládá.
Tvar příkazu:
pi=NSE>>vg(S, E, T, H)
Pro plochy mají příkazy NPO a NSE následující tvary:
pi=NPO>>vg(F),vi1,vi2
- **vg** — geometrický výraz typu F představující vyšetřovanou plochu,
- **vi1** — celočíselný výraz určující číslo oblasti plochy,
- **vi2** — celočíselný výraz, který může nabývat následujících hodnot:
  - **1** — počítá se počet bodů pro J=konst.,
  - **2** — počítá se počet bodů pro I=konst.,
  - **3** — počítá se index náběžné hrany (obvykle plochy typu "křídlo"),
  - **4** — počítá se počet oblastí modelu, význam hodnoty výrazu vi1 je potlačen,
  - **5** — zjišťuje se směr parametrizace přímkové plochy (pi=1 - přímky pro (I,u)=konst., pi=2 - přímky pro (J,v)=konst.),
  - **6** — zjišťuje se typ plochy
  - **7** — zjišťuje se počet bodů definičních křivek plochy typu 2 ("křídlo"),
  - **11** — zjišťuje se dolní mez indexu i (IMIN) oblasti plochy,
  - **12** — zjišťuje se horní mez indexu i (IMAX) oblasti plochy,
  - **21** — zjišťuje se dolní mez indexu j (JMIN) oblasti plochy,
  - **22** — zjišťuje se horní mez indexu j (JMAX) oblasti plochy.

Funkce NSE má tvar
pi=NSE>>vg(F),vi1,vi2
- **vg** — geometrický výraz typu F představující vyšetřovanou plochu,
- **vi1** — celočíselný výraz určující číslo oblasti plochy,
- **vi2** — celočíselný výraz, který může nabývat následujících hodnot:
  - **1** — počítá se počet plátů pro J=konst.,
  - **2** — počítá se počet plátů pro I=konst.,
  - **3** — počítá se index náběžné hrany (obvykle plochy typu "křídlo"),
  - **4** — počítá se počet oblastí modelu, význam hodnoty výrazu vi1 je potlačen,
  - **5** — zjišťuje se směr parametrizace přímkové plochy (pi=1 - přímky pro (I,u)=konst., pi=2 - přímky pro (J,v)=konst.),
  - **6** — zjišťuje se typ plochy
  - **7** — zjišťuje se počet bodů definičních křivek plochy typu 2 ("křídlo"),
  - **11** — zjišťuje se dolní mez indexu i (IMIN) oblasti plochy,
  - **12** — zjišťuje se horní mez indexu i (IMAX) oblasti plochy,
  - **21** — zjišťuje se dolní mez indexu j (JMIN) oblasti plochy,
  - **22** — zjišťuje se horní mez indexu j (JMAX) oblasti plochy.

### Výpočet indexu bodu na řetězci

#### `POS`
pi=POS>>vg1,vg2[,vi]
- **vg1** — geometrický výraz typu H,
- **vg2** — geometrický výraz typu Q,
- **vi** — celočíselný výraz představující výběrové číslo K.

Do celočíselné proměnné pi je uložená hodnota indexu uzlového bodu Q na řetězci H. Jestliže bod Q není uzlovým bodem řetězce H, je hlášena chyba. V případě, že bod Q je vícenásobným bodem řetězce H, provádí se výběr příslušného indexu výběrovým číslem K (výběr indexu K-tého uzlu Q - viz obr. 11.1). Default hodnota je K=1 (index prvního bodu Q na řetězci H).

### Určení indexu fiktivního spojení bodu řetězce

#### `FICT`
Jednotlivé části nesouvislého řetězce jsou odděleny tzv. fiktivním spojením bodů řetězce (viz odst. 6.4.1). Pro vyhledání indexu bodů řetězce, který je spojen s předchozím bodem fiktivní spojnicí, slouží funkce FICT (viz obr. 11.2). Tato funkce zjistí index prvního takového bodu za bodem, jehož index je možné zadat volitelným parametrem vi:
pi=FICT>>vg(E,H)[,vi]
kde uvedené parametry mají následující význam:
- **vg** — geometrický výraz typu E nebo H - řetězec, který je prohledáván,
- **vi** — celočíselný výraz - index bodu řetězce, který určuje, odkud je řetězec prohledáván. Není-li uveden, dosadí se implicitní hodnota 1.

Není-li fiktivní spojení ve vybrané části řetězce nalezeno, je hlášena chyba a hodnota proměnné pi není definovaná.

### Výpočet indexu při práci s maticemi

V systému GL-3 není možno deklarovat pole s dvěma indexy - maticí. Pro některé aplikace je však počítání se dvěma indexy výhodné. Proto byly do systému GL-3 zařazeny funkce IND, INDI a INDJ, které usnadňují použití pole s jedním indexem jako matice. Předpokládá se, že matice je v poli uložená po sloupcích, jak ukazuje níže uvedená tabulka, v níž čísla znázorňující prvky jsou pořadová čísla těchto prvků v poli:
```
			| sloupcový index j <<1,n>>
			---------------------------------------------------------------
			|	1	2	3	n=4
	---------------------------------------------------------------------------------------------
	řádkový index i	| 1 |	1	6	11 	16
	z intervalu <<1,m>>	| 2 |	2	7	12	17
			| 3 | 	3	8 	13	18
			| 4 |	4 	9 	14 	19
			| 5 |	5	10	15	20
```

Pro uložení matice s rozměrem m řádků a n sloupců potřebujeme pole o mxn prvcích. Pro výpočet pořadí prvků matice v poli platí následující výraz:
```
k=(j-1)*m+i
```

Pro zpětné získání indexu matice při známém rozměru matice a pořadí daného prvku v jednorozměrném poli platí tyto vztahy:
```
i=k-int((k-1)/m)*m
j=int((k-1)/m)+1
```

Funkce IND
#### `IND`
pi=IND>>vi1,vi2,vi3
Tato funkce počítá ze známých indexů i a j pořadí (index) v jednorozměrném poli. Jednotlivé parametry příkazu
mají následující význam:
- **vi1** — celočíselný výraz určující řádkový index matice (i),
- **vi2** — celočíselný výraz určující sloupcový index matice (j),
- **vi3** — celočíselný výraz udávající počet řádků matice (m).
#### `INDI`
Funkce INDI
pi=INDI>>vi1,vi2
Tato funkce počítá ze známého pořadí v jednorozměrném poli řádkový index matice (i). Jednotlivé parametry příkazu mají následující význam:
- **vi1** — celočíselný výraz určující pořadí prvků v jednorozměrném poli,
- **vi2** — celočíselný výraz udávající počet řádků matice.

Funkce INDJ
#### `INDJ`
pi=INDJ>>vi1,vi2
Tato funkce počítá ze známého pořadí v jednorozměrném poli sloupcový index matice (j). Jednotlivé parametry příkazu mají následující význam:
- **vi1** — celočíselný výraz určující pořadí prvků v jednorozměrném poli,
- **vi2** — celočíselný výraz udávající počet řádků matice.

## STAVOVÉ PŘÍKAZY

### Přiřazení stavových hodnot

Při spuštění programu zapsaném v jazyce GL-3 jsou systémem implicitně definovány určité stavové hodnoty (například při kreslení rychlost kreslení, velikost písma, typ čáry nebo při výstupu celých a racionálních čísel formát těchto čísel atd.). Tyto nastavené hodnoty lze v programu přestavit tzv. stavovými příkazy. Nastavení stavové hodnoty je v platnosti až do uvedení nového stavového příkazu. Tedy jestliže je na začátku programu uveden příkaz SIZE (nastavení velikosti textu), pak všechny popisy příkazy DTEXT, DNUMR, DNUMI, DTEXT3, DNUMR3, DNUMI3 uvedené za příkazem SIZE podléhají tomuto příkazu až do uvedení nového příkazu SIZE.

### Nastavení přesnosti aproximace křivek a prostorových kružnic (ACCUR)

#### `ACCUR`
Při výpočtech řezu plochou a nalezení izočáry plochy by měla být skutečným výsledkem těchto operací prostorová křivka. Protože však v jazyce GL-3 jsou křivky reprezentovány jen jako kubický spline, je výsledkem výše uvedených operací prostorový řetězec nahrazující skutečný řez (izočáru) s určitou přesností. Tato přesnost se nastavuje příkazem ACCUR.
Příkaz ACCUR nastavuje přesnost i pro procedury E45, H45 (náhrada rovinné a prostorové křivky řetězcem s přesností) a H96 (hrany tělesa rotací kolem přímky).
Při kreslení křivek a prostorových kružnic je použito úsečkové aproximace. To znamená, že tyto objekty jsou pro kreslení nahrazeny lomenou čárou s určitou přesností. I tuto přesnost předepisuje příkaz ACCUR.
Příkaz ACCUR tedy nastavuje přesnost pro výpočty s plochami, jejichž výsledkem je řetězec, pro procedury E45, H45 a H96, pro kreslení prostorových kružnic a konečně pro kreslení rovinných i prostorových křivek.
Tvar příkazu:
ACCUR[,vr]
Hodnota racionálního výrazu vr představuje nastavenou přesnost. Není-li uvedená nebo není-li v programu příkaz ACCUR použit, systém implicitně nastavuje hodnotu přesnosti na 0.01.

## VIRTUÁLNÍ SMLUVNÍ ORIENTACE

### Princip virtuální smluvní orientace

Smluvní orientace přímek, rovin a prostorových kružnic tak, jak je popsaná v odst. 6.3, může způsobovat obtíže při přípravě úloh řešících pohyb mechanismu. Kýve-li v dané úloze přímka okolo polohy, v níž nastává změna její smluvní orientace, stávají se algoritmy řešení, s ohledem na tuto změnu, nepřiměřeně složité. Tento jev lze účinně obejít zavedením tzv. virtuální (zdánlivé) smluvní orientace.
Uplatnění virtuální smluvní orientace nemění principy smluvní orientace popsané v odst. 6.3. Spočívá pouze ve výpočtu výběrového čísla pro danou geometrickou operaci pomocí speciální orientační funkce tak, aby se výběrové číslo v okamžiku nežádoucího překlopení smluvní orientace změnilo a tím vliv tohoto překlopení kompenzovalo. Funkce ovšem neodstraní vliv překlápění v plném rozsahu, pouze přesouvá okamžik změny do jiné polohy. Vnější efekt je stejný, jakoby osa smluvní orientace byla natočená do polohy uživatelem specifikované (viz situace na obr. 11.3).
Vstupní parametry pro orientační funkci jsou:
  - specifikace směru osy virtuální smluvní orientace,
  - objekt, který má vlivu virtuální smluvní orientace podléhat,
- virtuální výběrové číslo, vztažené k specifikovanému směru virtuální smluvní orientace.
Výstupem je hodnota skutečného výběrového čísla, kterou dosadíme do konkrétní geometrické operace.

### Rovinná orientační funkce

#### `ORI`
pi=ORI>>vg1,vg2,vi
Jednotlivé parametry vystupující v příkazu mají následující význam:
- **pi** — celočíselná proměnná, do níž se ukládá výsledné výběrové číslo,
- **vg1** — geometrický objekt typu A, V nebo L, jehož vektor určuje směr osy virtuální smluvní orientace,
- **vg2** — přímka nebo vektor, která má smluvní virtuální orientaci podléhat,
- **vi** — virtuální výběrové číslo vztažené k ose virtuální smluvní orientace.

Příklad 1:
Přímka L0 se otáčí okolo bodu P0 v rozmezí úhlu A z intervalu <<30,150>> po kroku 15 stupňů. Současně s přímkou se otáčí bod PN vypočtený ze vzájemné polohy P0 a L0 dle obr. 11.4.
```
	FOR,I=30,150,15
	A=FLOAT>>I 		<< Hodnota úhlu
	L0=L03>>P0,A 		<< Definice přímky L0
	IVIR=ORI>>LY,L0,1 	<< IVIR vypočteno pro L0 vzhledem
				<< ke směru LY a pro výběrové číslo
	PP=P17>>P0,L0,50,IVIR	<< Proměnná IVIR nahrazuje v obou
	PN=P18>>PP,L0,20,IVIR 	<< příkazech výběrové číslo 1
	PRINT,PN
	NEXT
	:

```

Poznámka pro řešení:
Abychom zabránili překlopení při přechodu úhlu 90 stupňů, nastavíme směr virtuální smluvní orientace do směru kladné osy y. Tak zajistíme, že v celém rozsahu dané úlohy k překlopení nedojde.
Příklad 2:
Přímka L0 se otáčí kolem bodu P0 o 360 stupňů po kroku 72 stupňů. V každé poloze vytne její kladné polopřímka na kružnici C bod PC dle obr. 11.5.
```
	DIMEN,PC(8)
	C=C00>>-30,0,80 	<< Definování kružnice
	A=25 			<< úhel urcující primku
	FOR,I=1,8
	L0=L03>>P0,A 		<< Definice přímky
	PC(I)=P21>>L0,C,(ORI>>A,L0,1)	<< Výpočet bodu - výběrové
				<< číslo nahrazeno orientační
				<< funkcí
	A=A+72			<< Změna úhlu a kroku
	NEXT
	:

```

Poznámka pro řešení:
Abychom zabránili překlápění při přechodech úhlů 90 a 270 stupňů, nastavíme směr virtuální smluvní orientace vždy totožný s úhlem určujícím okamžitou polohu přímky.

### Prostorová orientační funkce

#### `ORI3`
pi=ORI3>>vg1,vg2,vi
Jednotlivé parametry vystupující v příkazu mají následující význam:
- **pi** — celočíselná proměnná, do níž se ukládá výsledné výběrové číslo,
- **vg1** — geometrický objekt typu U, M, R nebo G, jehož vektor určuje směr osy virtuální smluvní orientace,
- **vg2** — geometrický objekt typu U, M, R nebo G, který má virtuální orientaci podléhat,
- **vi** — virtuální výběrové číslo vztažené k ose virtuální smluvní orientace.

Použití prostorové orientační funkce je zcela analogické použití funkce rovinné - viz příklady odst. 11.5.2.
