# PŘÍKAZY PRO PRÁCI S TEXTY

## PŘÍKAZ PRO PŘEMÍSŤOVÁNÍ ZNAKŮ NEBO SKUPIN ZNAKŮ MEZI TEXTOVÝMI PROMĚNNÝMI (TEXB)

#### `TEXB`
Tvar příkazu:
```
	TEXB,pt,[vi1],[vi2],vt[,vi3]

```

- **pt** — výsledná textová proměnná, do níž se přesun realizuje.
- **vt** — vstupní textový objekt, z něhož se přesun do výsledné textové proměnné pt provádí.
- **vi1** — celočíselný výraz udávající pozici ve výsledné textové proměnné, do níž bude uložen první přesunovaný znak. Minimální povolená hodnota vi1=1, maximální vi1=vi2, implicitně nastavená (default) hodnota vi1=1.
- **vi2** — celočíselný výraz udávající pozici ve výsledné textové proměnné, do níž bude uložen poslední přesunovaný znak. Minimální povolená hodnota vi2=vi1, maximální vi2=72, implicitně nastavená (default) hodnota vi2=72.
- **vi3** — celočíselný výraz udávající pozici ve vstupním textovém objektu, na níž se nachází první přesunovaný znak. Implicitně nastavená (default) hodnota vi3=1.

Příkaz TEXB přemísťuje znak nebo skupinu znaků z vi3-té a dalších pozic vt na vi1-tou a další pozice pt až do pozice vi2. Celkový počet přenášených znaků je (vi2-vi1+1).
Pokud má vstupní textový objekt méně než vi3 definovaných znaků (i mezera je definovaný znak), je hlášena chyba. Pokud je celkový počet přenášených znaků větší než počet definovaných znaků následujících za vi3-tou pozicí vt, přenesou se do pt všechny znaky počínaje vi3-tou pozicí vt až do konce vt a zbytek pozic v pt až do vi2-té pozice se doplní mezerami.
Další informace o příkazu TEXB viz odst. 15.4.
Příklad (znak '_' představuje mezeru):
```
		:
	B1='ABCDEFGHIJK'
	B2='ABCDEF'
	B3='A1_B2+C'
	TEXB,B1,4,9,B3,3
	TEXB,B2,10,20,B3
		:
```

Po této sekvenci příkazů budou mít textové proměnné B1 a B2 následující obsah:
```
	B1: ABC_B2+C_JK tj.		11 definovaných znaků
	B2: ABCDEF___A1_B2+C____	tj. 20 def. znaků
```

## PŘÍKAZ PRO VKLÁDÁNÍ RACIONÁLNÍHO ČÍSLA DO TEXTOVÉ PROMĚNNÉ (RNUMB)

#### `RNUMB`
Tvar příkazu:
```
	RNUMB,pt,[vi1],[vi2],vr[,vi3]

```

- **pt** — výsledna textová proměnná, do níž se vkládání realizuje.
- **vr** — racionální výraz (číslo), jehož hodnota má být vložena do výsledné textové proměnné.
- **vi1** — celočíselný výraz udávající pozici ve výsledné textové proměnné pt, od níž bude vkládané číslo vr uloženo. Minimální povolená hodnota vi1 = 1, maximální vi1 = (vi2-1), implicitně dosazená (default) hodnota vi1 = 1.
- **vi2** — celočíselný výraz udávající pozici v pt, po níž bude vkládané číslo vr uloženo. Minimální povolená hodnota vi2=(vi1+1), maximální vi2=72, implicitně dosazená (default) hodnota vi2=72.
- **vi3** — celočíselný výraz udávající počet míst za desetinnou tečkou, na něž má být vkládané číslo formátováno. Minimální povolená hodnota vi3=0, maximální vi3=71, implicitně dosazená (default) hodnota vi3=3. Zároveň musí platit vi3=<<(vi2-vi1).

Formát vkládaného čísla vr:
```
F<<vi2-vi1+1>>.<<vi3>>
```

Pokud je parametry vi1,vi2,vi3 špatně nastaven formát vkládaného čísla vr vzhledem k jeho velikosti, je hlášena chyba.
Je-li celkový počet míst racionálního čísla (pokud je číslo záporné, počítá se i místo pro znaménko) menší než hodnota (vi2-vi1+1), doplní se nastavený formát zleva mezerami. Je-li počet desetinných míst vkládaného čísla větší než hodnota parametru vi3, číslo se zaokrouhlí na počet desetinných míst určený hodnotou parametru vi3.
Další informace o příkazu RNUMB viz odst. 15.4.
Příklad (znak'_' představuje mezeru):
```
		:
	B1='HODNOTA_D1_CINI:'
	B2='130.47__>>__100.00'
	D1=125.3678
	RNUMB,B1,20,30,D1,4
	RNUMB,B2,,7,D1
		:
```

Po této sekvenci příkazů budou mít textové proměnné B1 a B2 následující obsah:
```
B1: HODNOTA_D1_CINI:______125.3678 	tj. 30 def. znaků
B2: 125.368_>>__100.00	  vkládané číslo se zaokrouhlilo
```

## PŘÍKAZ PRO VKLÁDÁNÍ CELÉHO ČÍSLA DO TEXTOVÉ PROMĚNNÉ (INUMB)

#### `INUMB`
Tvar příkazu:
INUMB,pt,[vi1],[vi2],vi3
- **pt** — výsledná textová proměnná, do níž se vkládání realizuje.
- **vi1** — celočíselný výraz udávající pozici ve výsledné textové proměnné pt, od níž bude vkládané číslo vi3 uloženo. Minimální povolená hodnota vi1=1, maximální vi1=vi2, implicitně nastavená (default) hodnota vi1=1.
- **vi2** — pozice v pt, do níž se přesune poslední cifra (nejnižší řád) vkládaného čísla vi3. Minimální povolená hodnota vi2=vi1, maximální vi2=72, implicitně nastavená (default) hodnota vi2=72.
- **vi3** — celočíselný výraz (číslo), jehož hodnota má být vložena do výsledné textové proměnné pt.

Formát vkládaného čísla vi3:
```
I<<vi2-vi1+1>>
```

Pokud je hodnota (vi2-vi1+1) větší než celkový počet míst vkládaného čísla (případně zvětšený o jedno místo na záporné znaménko), doplní se nastavený formát zleva mezerami. Pokud je špatně nastaven formát (parametry vi1,vi2) vkládaného čísla vi3 vzhledem k jeho velikosti, je hlášena chyba.
Další informace o příkazu INUMB viz odst. 15.4.
Příklad (znak '_' představuje mezeru):
```
		:
	B1='IY=123'
	I1=5432
	INUMB,B1,5,9,6789
	INUMB,B2,4,8,I1<<		B2 dosud nedefinováno
		:
```

Po této sekvenci příkazů budou mít textové proměnné B1 a B2 následující obsah:
```
B1: IY=1_6789
B2: ____5432
```

## VŠEOBECNÉ INFORMACE O ČINNOSTI PŘÍKAZU TEXB, RNUMB A INUMB

- Výsledná textová proměnná pt nemusí být před použitím v příkazech TEXB, RNUMB, INUMB definována.
- Není-li výsledná textová proměnná pt definována, naplní se všechny znaky na pozicích nižších než vi1 mezerami.
- Je-li pt definována, ale počet v ní uložených znaků (označme IZN) je menší než vi1 - 1, jsou pozice od znaku (IZN + 1) do znaku (vi1 - 1) včetně doplněny mezerami.
- Je-li pt definována, mění se pouze pozice v intervalu <<vi1; vi2>>. Text v intervalu <<vi1; vi2>> je přepsán, ostatní pozice jsou nezměněny.

## PŘÍKAZ PRO UKLÁDÁNÍ INFORMACE O DNI, DATU A ČASE DO TEXTOVÉ PROMĚNNÉ (DATE)

#### `DATE`
Tvar příkazu:
```
	DATE,pt,vi

```

- **pt** — textová proměnná, do níž bude informace uložena,
- **vi** — nepovinný celočíselný výraz. Hodnota výrazu je jedno až tříciferné výběrové číslo KKK skládající se z číslic 0 nebo 1. Číslice řádu stovek rozhoduje o uložení informace o dni v týdnu, číslice řádu desítek o uložení data, číslice řádu jednotek o uložení času. Je-li na místě určitého řádu číslice 0, příslušná veličina (den, datum, čas) se neukládá, je-li číslice 1, veličina se ukládá - viz příklad. Implicitně nastavená (default) hodnota vi = 10.

Informace o dni v týdnu zaujímá v textové proměnné 7 míst; má-li jméno dne méně než 7 písmen, doplní se zpráva mezerami.
Informace o datu má následující tvar:
```
DD-MMM-RR
```

- **DD** — den v měsíci
- **MMM** — měsíc
- **RR** — rok

Informace o čase má tvar:
HH:MM:SS
- **HH** — hodiny
- **MM** — minuty
- **SS** — sekundy

Jednotlivé informace (den, datum, čas) jsou od sebe navzájem odděleny dvěma mezerami.
Příklad (znak '_' představuje mezeru):
```
	příkaz: 		uloženo do text. proměnné B:

	DATE,B<<		22-sep-84
	DATE,B,1<<		09:55:50
	DATE,B,10<<		22-sep-84
	DATE,B,100<<		Sobota_
	DATE,B,11<<		22-sep-84__09:55:50
	DATE,B,101<<		Sobota___09:55:50
	DATE,B,110<<		Sobota___22-sep-84
	DATE,B,111<<		Sobota___22-sep-84__09:55:50
```
