# VSTUPNÍ A VÝSTUPNÍ PŘÍKAZY

## PŘÍKAZY PRO NASTAVENÍ VSTUP/VÝSTUPNÍHO ZAŘÍZENÍ

### Nastavení vstupního zařízení nebo otevření souboru pro formátovaný vstup - příkaz IDEV

#### `IDEV`
Tvar příkazu:
```
	IDEV,vt[,vi]

```

- **vt** — textový objekt,
- **vi** — celočíselný výraz udávající číslo vstupního kanálu.
```

```

Všechny následující vstupy (příkazy typu READ a typu GET) budou formátované a budou se realizovat z nastaveného vstupního souboru nebo vstupního zařízení na kanálu, který je definován celočíselnou hodnotou vi (viz odst. 8.1). Celočíselný výraz vi může nabývat pouze hodnoty 0, 1 nebo 2; v opačném případě je hlášena chyba. Není-li uveden vůbec, je dosazena implicitní hodnota 0. Jméno souboru je uvedeno v textové proměnné nebo textové konstantě vt.
Příklad:
```
	IDEV,BNAME
	IDEV,'J2.DAT',1

```

V případě vstupu ze vstupního zařízení obsahuje textový objekt vt jméno tohoto zařízení. V současné době je povolen pouze vstup z terminálu. Jako jméno terminálu je možné použít kterýkoli ze symbolů TI:, TT:, CON: případně TI, TT, a CON.
Příklad:
```
	IDEV,'TI:'[,vi]

```

nebo
```
	B='TI:'
	IDEV,B[,vi]
```

Realizuje-li se vstup ze souboru, je v textovém objektu vt uvedeno jeho jméno zapsané dle platných konvencí příslušného operačního systému. Není nutné uvádět jméno souboru v plném rozsahu. Při vynechání jeho některých částí se dosazují na místo neuvedených částí následující implicitní (default) hodnoty: adresář, na němž uživatel pracuje, rozšíření jména souboru .RDT a na počitačích typu VAX nejvyšší existující verze souboru. Vlastní jméno souboru musí být v programu vždy uvedeno.
Příklady:
```
	BNAME='J1.DAT'
	IDEV,BNAME
```

Následující vstupy realizované z implicitně nastaveného kanálu 0 příkazem READ nebo příkazem GET budou čteny z formátovaného souboru J1.DAT, který se nachází na adresáři, na němž uživatel právě pracuje. Na počitačích typu VAX jsou data načítána z nejvyšší existující verze souboru J1.DAT.
```
	IDEV,'C:\APL\GEOM\DATA.TXT'		<< Oper. sys.	MS DOS
	IDEV,'KON:[APL.GEOM]DATA.TXT;1'	<< Oper. sys.	VMS 11
```

Rovněž následující vstupy budou realizovány z implicitně nastaveného kanálu 0 a budou čteny ze souboru DATA.TXT, umístěného dle specifikace v příkazu uvedené.
Pokud v programu není příkaz IDEV, IDEVB (viz odst. 13.1.2) pro některý kanál uveden, nastavuje se na tomto kanálu při spuštění implicitně nastavený režim formátovaného čtení z terminálu.

### Nastavení vstupního zařízení nebo otevření souboru pro binární vstup - příkaz IDEVB

#### `IDEVB`
Tvar příkazu:
```
	IDEVB,vt[,vi]

```

- **vt** — textový objekt,
- **vi** — celočíselný výraz udávající číslo vstupního kanálu.
```

```

Všechny následující vstupy (příkazy typu READ a typu GET) budou binární a budou realizovány z nastaveného vstupního souboru na kanále, jehož hodnotu udává celočíselný výraz vi. Celočíselný výraz vi může nabývat pouze hodnoty 0, 1 nebo 2; v opačném případě je hlášena chyba. Není-li uveden vůbec, je dosazena implicitní hodnota 0. Jméno souboru je uvedeno v textové proměnné nebo textové konstantě vt. Binární vstup z terminálu není dovolen (je hlášena chyba).
Jméno vstupního souboru musí být zapsáno dle platných konvencí příslušného operačního systému. Není nutno uvádět jméno souboru v plném rozsahu. Při vynechání některých částí jména souboru se na tato vynechaná místa dosazují následující implicitní hodnoty: adresář, na němž uživatel pracuje, rozšíření jména souboru .RDB, na počitačích typu VAX nejvyšší existující verze souboru. Vlastní jméno souboru musí být v programu vždy uvedeno.
Není-li v programu pro některý kanál uveden příkaz IDEVB, resp. IDEV, nastavuje se na tomto kanálu při spuštění programu režim formátovaného čtení z terminálu.

### Nastavení výstupního zařízení nebo otevření souboru pro formátovaný výstup - příkaz ODEV

#### `ODEV`
Tvar příkazu:
```
	ODEV,vt[,vi]

```

- **vt** — textový objekt,
- **vi** — celočíselný výraz udávající hodnotu výstupního kanálu.
```

```

Všechny výstupy (příkazy typu PRINT, typu WRITE a typu TYPE) následující za příkazem ODEV budou formátované a budou se realizovat do výstupního souboru nebo na nastavené výstupní zařízení na kanále, který je definován hodnotou celočíselného výrazu vi. Celočíselný výraz vi může nabývat pouze hodnoty 0, 1 nebo 2; v opačném případě je hlášena chyba. Není-li uveden vůbec, je dosazena implicitní hodnota 0. Jméno výstupního zařízení nebo souboru je uloženo v textové konstantě nebo textové proměnné vt.
Jako výstupní zařízení je možné použít pouze terminál. V tom případě musí obsahovat textový objekt vt některý ze symbolů TI:, TT:, CON:, TI, TT, CON, jež představují jméno terminálu
Příklad:
```
	ODEV,'TI:'[,vi]

```

nebo
```
	B='TI:'
	ODEV,B[,vi]
```

Je-li příkazem ODEV nastaven výstupní soubor, pak jeho jméno musí být zapsáno dle platných konvencí příslušného operačního systému. Nemusí být uvedeno v plném rozsahu. Je-li vynechaná některá část jména, dosazují se na místa chybějících částí následující implicitně nastavené hodnoty: adresář, na němž uživatel pracuje, rozšíření jména souboru .WDT, na počitačích VAX verze souboru o jedničku vyšší než dosud existující (jestliže soubor neexistuje, vytváří se verze číslo 1). Vlastní jméno souboru musí být v příkaze ODEV uvedeno.
Není-li příkaz ODEV, resp. ODEVB (viz odst. 13.1.4) v programu pro některý kanál uveden, nastavuje se na tomto kanálu při spuštění programu režim formátovaného zápisu na terminál.
Příklad:
```
	ODEV,'AAA'
```

Na adresáři, ze kterého byl program spuštěn, se vytváří soubor  AAA.WDT.  Na počitačích typu VAX má tento soubor verzi o jednotku vyšší než soubor dosud existující.

#### `ODEVB`
Tvar příkazu:
```
	ODEVB,vt[,vi]

```

- **vt** — textový objekt,
- **vi** — celočíselný výraz udávající hodnotu výstupního kanálu.
```

```

Všechny výstupy (příkazy typu PRINT, WRITE a TYPE) následující za příkazem ODEVB budou binární a realizují se do výstupního souboru na kanále, který je definován celočíselnou hodnotou vi. Celočíselný výraz vi může nabývat pouze hodnoty 0, 1 nebo 2. Není-li uveden vůbec, je dosazena implicitní hodnota 0. Jméno souboru je uloženo v textové proměnné (nebo konstantě) vt. Nejsou povoleny výstupy na terminal.
Jméno souboru v příkaze ODEVB musí být zapsáno dle platných konvencí příslušného operačního systému. Nemusí být uvedeno v plném rozsahu. Je-li vynechaná některá část jména souboru, jsou na místa chybějících částí dosazeny následující implicitně nastavené hodnoty: adresář, na němž uživatel pracuje, rozšíření jména souboru .WDB, na počitačích typu VAX verze o jedničku vyšší než dosud existující. Vlastní jméno souboru musí být v příkaze ODEVB vždy uvedeno.
Není-li v programu pro některý kanál uveden příkaz ODEVB, resp. ODEV (viz odst. 13.1.3), nastaví se pro tento kanál implicitně režim formátovaného zápisu na terminál.

## PŘÍKAZY VSTUPU

### Příkazy čtení typu READ

#### `READ, READ1, READ2, READT`
Tvar příkazu:
```
	READ ,seznam parametrů
	READ1,seznam parametrů
	READ2,seznam parametrů
	READT,seznam parametrů
```

- **seznam parametrů** — -  obsahuje posloupnost geometrických, celočíselných nebo textových proměnných. Prvky seznamu jsou odděleny čárkami. Seznam nesmí obsahovat výrazy a konstanty.
Příkazy typu READ pro daný kanál přiřazují z nastaveného vstupního zařízení nebo souboru hodnoty proměnným uvedeným v seznamu parametrů dle daného pořadí, přičemž jeden jednoduchý objekt je načten z jednoho záznamu.
Provedení příkazu (příklad):
```
	READ,PA,VA

```

je ekvivalentní posloupnosti příkazu
```
	READ,PA
	READ,VA

```

Vysvětlení organizace příkazů typu READ se nachází v odstavci 8.2.1 pro jednoduché objekty a v odstavci 8.6 pro složené objekty.
Příklad:
Označme R - racionální číslo, I - celé číslo, B - textový řetězec maximálně o 72 znacích. Potom příkazem
```
	READ,B1,I1,C(2),CM

```

se ze vstupu přiřazeného kanálu 0 přečtou 4 záznamy následující struktury:
```
	B
	I
	R	R	R
	R	R	R

```

Přečtené hodnoty budou přiřazeny postupně proměnným B1, I1, C(2), CM.

### Příkazy čtení typu GET

#### `GET, GET1, GET2, GETT`
Tvar příkazu:
```
	GET ,seznam parametrů	
	GET1,seznam parametrů
	GET2,seznam parametrů	
	GETT,seznam parametrů

```

- **seznam parametrů** — -  posloupnost geometrických proměnných jednoduchých geometrických objektů a celočíselných proměnných. (Povolené typy proměnných - D, P, V, L, C, Q, U, R, M, G, I). Jednotlivé prvky seznamu jsou odděleny čárkami. Seznam nesmí obsahovat výrazy a konstanty.
```

```

Příkazy typu GET pro daný kanál přiřazují z nastaveného vstupního zařízení nebo souboru hodnoty uložené v jediném záznamu všem proměnným definovaným v seznamu parametrů - viz odst. 8.2.2. Poznamenejme, že příkazyem typu GET nelze přiřadit hodnoty textové proměnné nebo složenému geometrickému objektu.
Příklad:
Označíme-li I1, I2 - celá čísla, R1, . . .,R8 racionální čísla, pak příkazem
```
	GETT,ROV,JK,QB,JJ,D

```

se z terminálu přečte jediný záznam následující struktury:
```
	R1 R2 R3 R4 I1 R5 R6 R7 I2 R8

```

přičemž složky R1, R2, R3, R4 budou přiřazeny rovině ROV, celé číslo I1 bude obsahem celočíselné proměnné JK, bodu QB budou přiřazeny souřadnice (R5,R6,R7), v celočíselné proměnné JJ bude hodnota I2 a v racionální proměnné D bude hodnota R8.

### Příkaz pro přiřazení hodnot objektům - příkaz DATA

#### `DATA`
Tvar příkazu:
```
	DATA,p,vi
	parametry objektu
		:
	parametry objektu

```

- **p** — proměnná (povoleny typy - D, P, V, L, C, Q, U, R, M, G, I, B) - jednoduchý geometrický objekt, celočíselný objekt nebo textový objekt. Proměnná p určuje prvek v poli nebo v deklarované množině, počínaje kterým jsou do pole (množiny) proměnných přiřazovány parametry objektů ze seznamu uvedeného za vlastním příkazem. Pole (množina) musí být dříve definovaná příkazem DIMEN.
- **vi** — počet objektů, kterým má být přiřazena hodnota.
- **parametry objektu** — -  skupina reálných konstant, celých čísel nebo textových konstant podle typů objektů oddělených čárkami. Počet konstant musí odpovídat hodnotě celočíselného výrazu vi, jinak je hlášena chyba, ale na jednom řádku může být zapsáno více objektů. Počty konstant pro jednotlivé objekty se řídí následující tabulkou:
```
				objekt typu	B		1 text. konstanta (max. 72 znaků)
						I		1 celé číslo
						A, D		1 rac. číslo
						P, V		2 rac. čísla
						C, Q, U	3 rac. čísla
						L, R		4 rac. čísla
						M		6 rac. čísel
						G		7 rac. čísel

```

Množina objektů, jíž jsou hodnoty přiřazovány jediným příkazem DATA, může obsahovat jen jediný typ objektu - viz příklad 2.
Příklad 1.:
```
	DIMEN,BTEXT(4)
		:
	DATA,BTEXT,3
	'ARITMETICKE OPERACE','PLUS','MINUS'

```

Příkaz přiřadí poli BTEXT tyto texty:
```
	BTEXT(1)...ARITMETICKE OPERACE
	BTEXT(2)...PLUS
	BTEXT(3)...MINUS
	BTEXT(4)...dosud nedefinováno

```

Příklad 2.:
```
	DIMEN,QX(2),QY(3)
		:
	DATA,QX(2),2
	30,-40,10,  1
	2,1

```

Příkaz přiřadí prostorovým bodům QX a QY následující hodnoty:
```
	QX(1).........není dosud definován
	QX(2)......... 30 -40 10
	QY(1)......... 1 2 1
	QY(2),QY(3)...nejsou dosud definovány

```

### Nestandardní příkaz čtení plochy LOADF

#### `LOADF`
Tvar příkazu:
```
	LOADF,pg,vt[,[vi1],[vi2],[vi3],[vi4],[vi5]]

```

- **pg** — identifikátor plochy (objekt typu F),
- **vt** — jméno souboru, který obsahuje řídící body plochy (implicitně nastavený typ .PLG),
- **vi1** — způsob připojení plochy
  - =1 plocha pg bude definovaná jako nová (implicitně nastavená hodnota),
  - =0 plocha načtená ze souboru .PLG bude připojena jako další     oblast k dříve definované ploše pg,
- **vi2,vi3,vi4,vi5** — - tyto parametry určují meze oblasti plochy IMIN, IMAX, JMIN, JMAX v uvedeném pořadí. Není-li některá hodnota uvedená (nebo všechny) je dosazen maximální rozsah ze souboru .PLG
```

```

UPOZORNĚNÍ: Příkaz LOADF lze použít pouze na počitačích typu VAX!
Příklad:
```
	LOADF,FT,'DBGT:TST610'

```

Tento příkaz definuje novou plochu FT (bez ohledu na to, zda již byla nebo nebyla definovaná). Tato plocha obsahuje celou plochu, která byla uložená v souboru TST610.PLG na zařízení DBGT:.
```
	LOADF,FT,'DBGT:TZD610',0,,,2,11

```

Tento příkaz připojí k dříve definované ploše FT další oblast, určenou celým rozsahem indexu i a rozsahem 2-11 indexu j z plochy, uložené v souboru TZD610.PLG na zařízení DBGT:.

### Speciální příkaz vstupu plochy FLOAD

#### `FLOAD`
Tvar příkazu:
```
	FLOAD,pg,vt[,[vi1],[vi2],[vi3],[vi4],[vi5],[vi6]]

```

- **pg** — identifikátor plochy (objekt typu F),
- **vt** — jméno souboru, který obsahuje řídící body plochy (implicitně nastavený typ .SUR),
- **vi1** — způsob připojení plochy
  - =1 plocha pg bude definovaná jako nová (implicitně nastavená hodnota),
  - =0 plocha načtená ze souboru .SUR bude připojena jako další oblast k dříve definované ploše.
- **vi2,vi3,vi4,vi5** — - tyto parametry určují meze oblasti plochy IMIN, IMAX, JMIN, JMAX v uvedeném pořadí. Není-li některá hodnota uvedena (nebo všechny), je dosazen maximální rozsah ze souboru .SUR,
- **vi6** — číslo oblasti plochy. Jestliže vi6=0, načtou se všechny oblasti plochy nezávisle na nastavených mezích. Jestliže vi6 není uvedeno a alespon jedna z mezí je explicitně uvedena, načte se první oblast plochy s příslušnými mezemi; jestliže vi6 není uvedeno a explicitně není uvedena ani jedna z mezí, načtou se do proměnné pg všechny oblasti plochy.

UPOZORNĚNÍ: Příkaz FLOAD lze použít pouze na personálních počitačích!

Příklad:
```
	FLOAD,F1,'C:\SUR\FKSTK',,,,3,5,2

```

Tento příkaz definuje novou plochu F1 bez ohledu na to, zda již byla v programu definována. Plocha F1 obsahuje část druhé oblasti plochy uložené v souboru C:\SUR\FKSTK.SUR danou rozsahem 3-5 indexu j.

## PŘÍKAZY VÝSTUPU

### Příkazy výstupu typu PRINT

#### `PRINT, PRINT1, PRINT2, PRINTT`
Tvar příkazu:
```
	PRINT ,seznam parametrů
	PRINT1,seznam parametrů
	PRINT2,seznam parametrů
	PRINTT,seznam parametrů

```

- **seznam parametrů** — - posloupnost výrazů, proměnných a konstant, představujících geometrické nebo celočíselné objekty. (Povolené typy objektů - D, P, V, L, C, S, E, Q, U, R, M, G, T, H, F, I). Jednotlivé prvky seznamu jsou odděleny čárkami.
Příkazy typu PRINT pro daný kanál (viz odst. 8.3.1) zapíší na nastavené výstupní zařízení nebo do nastaveného výstupního souboru hodnoty objektů specifikovaných v seznamu parametrů, přičemž hodnoty jednoho objektu se zapisují do jednoho záznamu (u jednoduchých objektů) nebo do více záznamů (u složených geometrických objektů).
Příklad:
Označíme-li I celé číslo a R racionální číslo, pak příkazem
```
	PRINT1,C,L(2),IK

```

se na výstupní zařízení nastavené na kanále číslo 1 zapíší 3 záznamy následující struktury (jsou-li všechny 3 objekty definovány):
```
	C(1)	R R R
	L(2)	R R R R
	IK(1)	I
```

### Příkaz výstupu na terminál TRACE

#### `TRACE`
Tvar příkazu:
```
	TRACE,seznam parametrů

```

- **seznam parametrů** — - posloupnost výrazů, proměnných a konstant, představujících geometrické nebo celočíselné objekty. (Povolené typy objektů - D, P, V, L, C, S, E, Q, U, R, M, G, T, H, F, I.) Jednotlivé prvky seznamu jsou odděleny čárkami.
```

```

Příkaz TRACE je plně ekvivalentní příkazu PRINTT (viz odst. 8.3.2), z čehož vyplývá, že zapíše na terminál hodnoty objektů specifikovaných v seznamu parametrů, přičemž hodnoty jednoho objektu se zapisují do jednoho záznamu (u jednoduchých objektů) nebo do více záznamů (u složených objektů).
```

```

### Příkazy výstupu polí a množin objektů - příkazy typu WRITE

#### `WRITE, WRITE1, WRITE2, WRITET`
Tvar příkazu:
```
	WRITE ,seznam parametrů
	WRITE1,seznam parametrů
	WRITE2,seznam parametrů
	WRITET,seznam parametrů

```

- **seznam parametrů** — - posloupnost výrazů, proměnných a konstant, představujících geometrické nebo celočíselné objekty. Dále je povolen symbol skládající se z písmene typu a znaku @. (Povolené typy objektů - D, P, V, L, C, S, E, Q, U, R, M, G, T, H, F, I). Jednotlivé prvky seznamu jsou odděleny čárkami.
```

```

Příkazy typu WRITE pro daný kanál slouží k tisku polí nebo tisku všech objektů daného typu na nastavené výstupní zařízení nebo do nastaveného výstupního souboru. Je-li v seznamu parametrů uveden identifikátor pole, tisknou se všechny dosud definované prvky tohoto pole. Je-li v seznamu parametrů uveden symbol sestávající se z písmene označujícího typ objektu a znaku @, tisknou se všechny definované objekty daného typu - viz odst. 8.3.3. Je-li v seznamu parametrů identifikátor prosté nebo indexované proměnné, výraz nebo konstanta, chovají se příkazy typu WRITE stejně jako příkazy typu PRINT.
Příklad:
Nechť I značí celé a R racionální číslo. Pak příkaz
```
	WRITE2,Q,I,U(4),G@

```

na výstupní zařízení nastavené na kanálu číslo 2 zapíše 6 záznamů následující struktury:
```
	Q(1)	R R R
	Q(2)	R R R
	Q(3)	R R R
	I(1)	I
	U(4)	R R R
	GTT(1)	R R R R R R R

```

za předpokladu, že z pole Q jsou definovány prvky Q(1), Q(2), Q(3), dále že je definována proměnná I a prvek U(4) z pole U a konečně, že je definována proměnná GTT jako jediná proměnná typu G.

### Příkazy výstupu typu TYPE

#### `TYPE, TYPE1, TYPE2, TYPET`
Tvar příkazu:
```
	TYPE ,seznam parametrů
	TYPE1,seznam parametrů
	TYPE2,seznam parametrů
	TYPET,seznam parametrů

```

- **seznam parametrů** — - posloupnost výrazů, proměnných a konstant, představujících jednoduchý geometrický, celočíselný nebo textový objekt. (Povolené typy objektů - D, P, V, L, C, Q, U, R, M, G, I, B). Jednotlivé prvky seznamu jsou odděleny čárkami.
```

```

Příkazy typu TYPE pro daný kanál (viz odst. 8.3.4) zapíší do jediného záznamu na nastavené výstupní zařízení nebo do nastaveného výstupního souboru hodnoty objektů uvedených v seznamu parametrů.
```

```

Příklad:
```
	BO='BOD Q'
	TYPE,BO,QA,'  LEZI NA KRIVCE T'

```

Jestliže bod QA má souřadnice [50,23.5,0], do souboru otevřeného na kanále 0 se příkazem ODEV zapíše jediný záznam:
```
	BOD Q 50.000 23.500 0.000 LEZI NA KRIVCE T

```

### Nestandardní příkaz výstupu plochy PLG

#### `PLG`
Tvar příkazu:
```
	PLG,pg,vi1,vi2,[vi3],vt[,[vi4],[vi5]]

```

- **pg** — identifikátor pole prostorových bodů, které obsahuje řídící body plochy,
- **vi1,vi2** — počet řídících bodů v poli pg, vi1 - počet ve směru i, vi2 - počet ve směru j,
- **vi3** — způsob připojení
  - =1 vznikne nový soubor .PLG,
  - =0 řídící body uložené v poli pg budou zapsány do souboru .PLG, který byl zřízen již dříve,
```
(implicitně nastavená hodnota je 1),
```

- **vt** — jméno souboru (implicitně nastavený typ je .PLG),
- **vi4,vi5** — indexy i a j, na které se umístí první řídící bod plochy (s nejnižším indexem v poli pg), (implicitně nastavené hodnoty vi4, vi5 jsou 1, 1).
```

```

UPOZORNĚNÍ: Příkaz PLG lze použít pouze na počitačích typu VAX!
```

```

Příklad:
```
	PLG,Q(10),4,5,'PLOCHA'

```

Tento příkaz uloží do nově vzniklého souboru PLOCHA.PLG řídící body plochy z pole Q. První bod, který bude umístěn na indexech 1, 1 je v prvku Q(10) a celkem bude uloženo 4*5=20 řídících bodů plochy. Na obr. 13.1 je čísly vyznačeno pořadí řídících bodů plochy v poli Q. Výše uvedený příkaz odpovídá obr. 13.1 a). Pro plochu na obr. 13.1 b) by příkaz PLG vypadal takto :
```
	PLG,Q(10),5,4,'PLOCHA'

```

### Speciální příkaz výstupu plochy FSAVE

#### `FSAVE`
Tvar příkazu:
```
	FSAVE,vg,vt

```

- **vg** — geometrický výraz typu F určující ukládanou plochu,
- **vt** — textová proměnná, která definuje jméno souboru, do něhož se plocha ukládá, implicitně nastavené rozšíření jména souboru je .SUR. Soubor se nachází na adresáři, který je v proměnné vt specifikován. Jestliže vt neurčuje adresář, plocha se ukládá na adresáři, z něhož byla úloha spuštěna.
```

```

UPOZORNĚNÍ: Příkaz FSAVE lze použít pouze na personálních počitačích!
Příklad:
```
	FSAVE,(F05>>FX,2,5],'FKSTK'

```

Plocha, která je definována operací F05 se uloží do souboru FKSTK.SUR, který vznikne na adresáři, z něhož je úloha spuštěna.
```

```

### Příkaz k vynechání řádků v tisku - příkaz LINE

#### `LINE`
Tvar příkazu:
```
	LINE[,[vi1][,vi2]]

```

- **vi1,vi2** — celočíselné výrazy.
```

```

Příkaz LINE vynechává na výstupním zařízení nastaveném na kanálu vi2 (implicitně nastavená hodnota kanálu je vi2=0) počet řádků specifikovaný celočíselným výrazem vi1. Není-li výraz vi1 uveden je vynechán jeden řádek. Jestliže parametr vi2 je uveden a nenabývá některé z hodnot 0, 1 nebo 2, je hlášena chyba (viz odst. 8.5.1).
```

```

### Příkaz k nastavení nové stránky - příkaz PAGE

#### `PAGE`
Tvar příkazu:
```
	PAGE[,vi]

```

- **vi** — celočíselný výraz.
```

```

Příkaz PAGE nastavuje novou stránku na výstupním zařízení nebo v souboru specifikovaném na kanále vi. Jestliže parametr vi je uveden a nenabývá některé z hodnot 0, 1 nebo 2, je hlášena chyba (viz odst. 8.5.1). Implicitně nastavená hodnota je vi=0 (je nastaven kanál 0).

### Příkaz k vypnutí tisku chybových hlášení - příkaz NOMESS

Příkaz NOMESS potlačuje výstupy chybového hlášení na všechna nastavená výstupní zařízení i na terminál. Implicitně je výstup chybových hlášení zapnut (viz odst. 8.5.2).

Příkaz MESS zapíné výstup chybového hlášení na všechna nastavená výstupní zařízení i na terminál. Pro binární výstupy jen na terminál (viz odst. 8.5.2).

### Potlačení tisku hlavičky programu a identifikátorů objektů - příkaz NOHEAD

#### `NOHEAD`
Tvar příkazu:
```
	NOHEAD[,vi]

```

- **vi** — celočíselný výraz.
Příkaz NOHEAD potlačuje na nastaveném kanálu specifikovaném celočíselným výrazem vi (implicitní hodnota je vi=0 - tj. na kanál 0) tisk úvodní hlavičky programu, identifikátorů geometrických a celočíselných objektů (při výstupu příkazy typu PRINT, typu WRITE a příkazem TRACE) a závěrečnou informaci o spotřebě času (viz odst. 8.5.3).
```

```

### Příkaz k nastavení formátu celých čísel - příkaz FORMI

#### `FORMI`
Tvar příkazu:
```
	FORMI[,vi]

```

- **vi** — celočíselný výraz.
```

```

Příkaz FORMI přestavuje výstupní formát celých čísel pro příkazy typu TYPE. Tento formát je přestaven na hodnotu danou celočíselným výrazem vi. Hodnota výrazu vi nám udává počet platných míst včetně znaménka, na něž se číslo zapisuje. Je-li číslo záporné, počítá se i místo pro znaménko. Bude-li formát nastavený hodnotou výrazu vi překročen, bude hlášena chyba. Je-li hodnota vi větší než počet míst, doplní se číslo zleva mezerami. Implicitně nastavená (default) hodnota je FORMI,5 (viz odst. 8.5. 4).
Příklad:
```
	I2=-2
	FORMI,4

```

číslo I2 vystupuje ve tvaru _ _-2 (znak '_' představuje mezeru).

### Příkaz k nastavení formátu racionálních čísel - příkaz FORMR

#### `FORMR`
Tvar příkazu:
```
	FORMR[,[vi1][,vi2]]

```

- **vi1,vi2** — celočíselné výrazy.
```

```

Příkazem FORMR přestavujeme výstupní formát racionálních čísel pro příkazy typu TYPE. Tento přestavovaný formát je dán hodnotami celočíselných výrazů vi1, vi2. Hodnota výrazu vi1 udává celkový počet míst racionálního čísla, na něž se číslo zapisuje (včetně desetinné tečky). Je-li číslo záporné, počítá se i místo pro znaménko. Hodnota výrazu vi2 udává počet platných míst za desetinnou tečkou. Bude-li formát nastavený hodnotami výrazu vi1 a vi2 překročen, bude hlášena chyba. Implicitně nastavené (default) hodnoty jsou FORMR,13,3 (viz odst. 8.5.4).
```

```

Příklad:
```
	D1=-150.234
	D2=15.21
	D3=15.23456
	FORMR,7,3

```

Při číselném nebo grafickém výstupu čísla D1 je hlášena chyba (-150.234 nelze zapsat na 7 míst), číslo D2 vystupuje ve tvaru
```
	_15.210

```

číslo D3 ve tvaru
```
	_15.235

```

(zaokrouhlí se); (znak '_' představuje mezeru).
