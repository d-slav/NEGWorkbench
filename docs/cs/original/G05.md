# POUŽITÍ SYNONYM V JAZYCE GL-3

## ROZSAH A OMEZENÍ POUŽITÍ SYNONYM

Pro zvýšení pohodlí při sestavování programu si uživatel může definovat namísto buďto všech, nebo jen vybrané skupiny klíčových slov a operátorů, snáze zapamatovatelná synonyma. Tato synonyma pak může v zápisu programu použít namísto původních operátorů.
Např. program
```
	READ,PA,PB,PC,PD
	LAB=L04>>LA,PB
	LCD=L04>>PC,PD
	PRUS=P20>>LAB,LCD
	PRINT,PRUS
	END

```

můžeme s použitím předem definovaných synonym (v souboru AAA.SNF)
```
	READ = CTI
	PRINT = TISK
	L04 = PRIM2B
	P20 = PRUS2P
	END = KONEC

```

zapsat takto:
```
	SYBFIL,$AAA
	CTI,PA,PB,PC,PD
	LAB=PRIM2B>>PA,PB
	LCD=PRIM2B>>PC,PD
	PRUS=PRUS2P>>LAB,LCD
	TISK,PRUS
	KONEC

```

## DEFINOVÁNÍ UŽIVATELSKÉHO SOUBORU SYNONYM

Pro definování uživatelského souboru synonym je nutno sestavit zdrojový soubor synonym. Je to textový soubor (vytvořený editorem), který má tvar:
```
	klíč_slovo_1 = syn_1
	klíč_slovo_2 = syn_2
	:         :
	klíč_slovo_i = syn_i
	:         :
	klíč_slovo_n = syn_n

```

- **'klíč_slovo_i'** — klíčové slovo nebo operátor 	alfanumerického výrazu, který má být synonymem nahrazen.
- **'syn_i'** — synonymum - řetězec o délce 1 až 12 alfanumerických znaků.
```

```

Synonymum je od klíčového slova odděleno rovnítkem. Kromě rovnítka může být mezi obě části záznamu vložen libovolný počet mezer, resp. tabulátorů.
Jednomu klíčovému slovu nebo geometrickému operátoru může být přiřazeno i více synonym. Soubor synonym může mít různý obsah - od několikařádkové podmnožiny až po úplnou síť příkazů. Jméno souboru je libovolné, definované uživatelem. Doporučený typ je .SNS. Po vytvoření vlastního uživatelského souboru synonym se spustí tvořící program příkazem
```
$STOSYN
```

Program si vyžádá jméno vstupního souboru, t.j. zdrojového souboru synonym. Zdrojový soubor pak zpracuje a vytvoří vlastní uživatelský soubor. Ten je neformátovaný, má stejné jméno jako zdrojový soubor a typ .SNF. Teprve s tímto souborem pak pracuje překladač GLC.

## AKTIVOVÁNÍ SOUBORU SYNONYM

Překladač GLC není automaticky vázán k žádnému uživatelskému souboru synonym. Neprovedeme-li tedy aktivaci některého tohoto souboru, překladač žádná synonyma nerozezná a při jejich výskytu ohlásí chybu.
Aktivace uživatelského souboru synonym je provedena příkazem SYNFIL, zapsaným ve zdrojovém textu programu v jazyku GL-3. Tento příkaz otevírá specifikovaný soubor synonym a nastavuje příznak jeho použití. Od toho okamžiku překladač rozezná jak původní klíčová slova a geometrické operátory, tak i synonyma definovaná v momentálně otevřeném souboru. Platnost aktivace trvá až do provedení dalšího příkazu SYNFIL, kterým se původně aktivovaný soubor uzavírá a aktivuje se soubor jiný.
Aktivační příkaz má tvar:
```
	SYNFIL,jméno
```

- **'jméno'** — jméno uživatelského souboru synonym. Je sestaveno podle konvencí použitého operačního systému. Má-li soubor typ .SNF, nemusí být tento typ v zápisu jména uveden.
Příkaz může být zapsán také takto:
```
	SYNFIL,$jméno
```

Jméno v tomto případě nesmí mít uvedeno zařízení. Je pak automaticky doplněno na tvar
```
	IGL3:jméno
```

(Předpokládá se, že na zařízení a adresáři označeném logickým jménem IGL3 budou uloženy soubory synonym obecné platnosti. V současné době takové soubory ještě neexistují.)

## OMEZENÍ POUŽITÍ SYNONYM

Synonyma je možno definovat pro všechny operátory geometrických příkazů bez výjimky a pro všechna klíčová slova s výjimkou slov:
```
	SYNFIL SUBRO DIMEN
```

Synonyma nelze použít před aktivováním souboru synonym příkazem SYNFIL, tedy před uvedením tohoto příkazu v programu. Není možné pracovat s více soubory synonym současně. Při opakovaném použití příkazu SYNFIL se dříve aktivovaný soubor uzavírá a aktivován zůstane soubor uvedený posledním příkazem SYNFIL.
Při používání synonym doporučujeme jistou obezřetnost. Je nutno si uvědomit, že program zapsaný s použitím synonym se může stát osobám, které daný soubor synonym neznají, prakticky nesrozumitelným.
