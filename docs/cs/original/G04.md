# SYNTAX V JAZYKU GL-3

## PŘÍKAZY A JEJICH DĚLENÍ Z HLEDISKA SYNTAXE

Příkaz je sekvence znaků, zapsaná podle daných syntaktických pravidel. Příkaz jednoznačně určuje činnost, jež bude při jeho zpracování provedena. Z hlediska formy zápisu jsou příkazy rozděleny do šesti skupin. Jsou to
  - geometrické příkazy,
  - přiřazovací příkazy,
  - výkonné příkazy,
  - rozhodovací příkazy,
  - kreslící příkazy,
- technologické příkazy.
Tyto skupiny nejsou zcela totožné se sémantickým tříděním příkazů. Znamená to, že např. ve skupině geometrických příkazů mohou být i příkazy, které vykonávají jiné operace než geometrické. Názvy jednotlivých skupin jsou odvozeny od činnosti, pro níž příkazy v dané skupině převládají.

## GEOMETRICKÉ PŘÍKAZY

Obecný tvar příkazu
```
		výsledek = geometrický_výraz

```

- **`výsledek`** — proměnná pg nebo pi. Typ proměnné musí odpovídat operátoru výrazu na levé straně a je kontrolován překladačem.
- **`geometrický_výraz`** — výraz vg dle popisu v odst. 3.7.
Geometrický výraz použitý přímo za rovnítkem příkazu nemusí být uzavřen v okrouhlých závorkách.
Příklady geometrických příkazů:
```
		VEC=V00>>10,3
		PDX=P13>>PPC,(P00>>5,10),(DS*2)
		IPOC=NTEX>>BNAM

```

Do této skupiny patří všechny příkazy pro geometrické výpočty, matematické funkce, vzájemné převody racionálních a celočíselných hodnot a příkazy pro kvantifikaci (počet bodů v řetězci, znaků v textové proměnné apod.)

## PŘIŘAZOVACÍ PŘÍKAZY

Obecný tvar příkazu
```
		výsledek = pravá_strana

```

- **`výsledek`** — některá z proměnných pg(D), pi, pt. Typ proměnné musí odpovídat typu pravé strany.
- **`pravá_strana`** — některý z výrazů vr, vi, vt. Výrazy vr a vi musí odpovídat popisu odst. 3.6. Nemusí být uzavřeny do okrouhlých závorek.
Příklady přiřazovacích příkazů
```
		DRC=5
		DM=ACP*(DP+5)/2.5-ACS
		ICR=J*(I-1)
		BT='Vypočtená hodnota:'
		BX=BT

```

Do této skupiny patří příkazy aritmetické (celočíselné i racionální) a prosté příkazy přiřazovací (celočíselné, racionální i textové).

## VÝKONNÉ PŘÍKAZY

Obecný tvar příkazu
```
		klíčové_slovo, seznam_parametrů

```

- **`klíčové_slovo`** — řetězec tří až šesti alfanumerických znaků jednoznačně definující operaci příkazem vyjádřenou.
- **`seznam_parametrů`** — parametry potřebné k provedení dané operace. Jednotlivé parametry jsou odděleny čárkami. Počet a typ parametrů je přiřazen jednotlivým klíčovým slovům a je kontrolován překladačem.
Obecně je v seznamu parametrů výkonného příkazu povolen každý objekt použitelný v jazyku GL-3 (vg, vr, vi, pg, pi, pt, kr, ki, kt). Konkrétní omezení je uvedeno u jednotlivých příkazů a je kontrolováno překladačem (v některých případech až výkonným programem).
Pro některé příkazy je seznam parametrů prázdný. Příkaz má tedy tvar:
```
		klíčové_slovo

```

Do skupiny výkonných příkazů patří i čtyři příkazy - FOR, TFN, SUBRO a CALL - které se od ostatních příkazů syntakticky mírně odlišují. Pro jejich snadnější čitelnost jsou některé z oddělovačů v seznamu parametrů (znak ' , ') nahrazený znakem '=' (příkaz FOR) nebo ' / ' (příkazy TFN, SUBRO, CALL).
```
		ODEV,BNM
		INI,PPP,DSC,KEY,1,'GRAF1'
		INCRE
		FOR,I=1,J
		DTEXT,(P00>>19.1,20.3),0,BX
		CMAC,PSS,DC,3.4,10,'KOKA'

```

Do této skupiny patří příkazy pro řízení chodu programu, příkazy pro vstupy a výstupy objektů, příkazy pro změnu stavu systému a příkazy pomocné, dále transformační příkazy a některé příkazy kreslící. Konečně sem patří část příkazů pro programování číslicového řízení.

## ROZHODOVACÍ PŘÍKAZY

Obecný tvar příkazu
```
		složená_podmínka / akce
nebo
		podmínka / akce

```

- **`složená_podmínka`** — má tvar:
```
 			podmínka / . logický_operátor . podmínka

			nebo

			podmínka / . logický_operátor . složená_podmínka

```

- **`logický_operátor`** — řetězec dvou až čtyř abecedních znaků, které  popisují logickou operaci nad oběma podmínkami
- **`podmínka`** — má tvar:
```
			klíčové_slovo / logický_výraz

```

- **`klíčové_slovo`** — řetězec dvou až čtyř abecedních znaků jednoznačně definujících operaci (viz odst. 12.2).
- **`logický_výra`z** — dva možné typy odpovídající příslušnému klíčovému slovu
    - některá z proměnných pg, pi, pt  (zkouší se definovanost nebo nedefinovanost uvedeného objektu),
    - relace (vyhodnocuje se vzájemný vztah dvou objektů).
- **`relace`** — má tvar:
```
			objekt1 . relační_operátor . objekt2

```

- **`objekt1`** — některý z výrazů vg, vr, vi, vt.
- **`objekt2`** — některý z výrazů vg, vr, vi, vt. Povolené typy obou objektů jsou závislé na klíčovém slově.
- **`relační_operátor`** — řetězec  dvou  abecedních  znaků vyjadřující vztah mezi oběma objekty v relaci uvedenými.
- **`akce`** — má tři možné varianty:
```
				1.	<M>příkaz
<M>
				2.	THEN
					   :
					 příkaz
<M>					 příkaz
					   :
					ENDIF

				3.	THEN
					 příkaz
					 příkaz
					   :
					ELSE
					   :
					 příkaz
					 příkaz
					   :
					ENDIF

```

'příkaz' - libovolný příkaz  jazyka  GL-3  s omezeními podle odst. 12.2.
Příklady rozhodovacích příkazů:
```
		IFN/QR(J)/20
		IFY/PRU.EQ.(P20>>L1,L2)/MOVE/E:0*E
		IFT/BTX.NE.'ANO'/.AND.IFN/L1/THEN
		    J=I*(J+3)
		    MOVE/P1*VX
		ENDIF
		IFI/I.GT.J/THEN
		   K=I
		ELSE
		   K=J
		ENDIF

```

Do této skupiny patří výhradně příkazy pro větvení programu (viz odst. 12.2).

## KRESLÍCÍ PŘÍKAZY

Obecný tvar příkazu
```
		klíčové_slovo|fráze|fráze|....|fráze

```

- **`klíčové_slovo`** — řetězec tří až šesti alfanumerických znaků jednoznačně definující operaci.
- **'|'** — oddělovač frází - dva možné  znaky,
    - znak  ' * '   -   piš,
    - znak  ' /  '   -   nepiš.
- **`fráze`** — seznam jednoho až čtyř parametrů oddělených  znaky  '  :  ' ,  '  # '  nebo  ' , ' (oddělovače se liší svým významem). Jako parametr ve frázi může být uveden výraz vg, vr nebo vi.
Příklad kreslícího příkazu
```
		MOVE/P0*PN*DX:DY/LA:LB*PC*10

```

Do této skupiny patří výhradně příkazy pohybové.

## TECHNOLOGICKÉ PŘÍKAZY

Obecný tvar příkazu
```
		$textový_řetězec

```

Příkazy tohoto typu nejsou přímo zpracovávány ani při překladu, ani při chodu výkonného programu. Jsou pouze překopírovány do souboru CL2 (viz odst. 17.1 a kap. 22). Jsou pak zpracovány až meziprocesorem při transformaci souboru CL2 pro obrábění. Jejich syntaxe není překladačem GLC kontrolována. Tyto příkazy slouží ke sdílení technologických, speciálních geometrických i jiných informací, které jsou pro obrábění nezbytné.
Příklady technologických příkazů
```
		$CHLAZENI,ZAP
		$OTACKY,1200

```

Do této skupiny patří výhradně technologické příkazy s konstantními parametry.

## PARAMETRY DEFINOVANÉ IMPLICITNĚ  (DEFAULT)

V popisech geometrických a výkonných příkazů jsou některé parametry zapsány v hranatých závorkách. Tyto parametry jsou z hlediska syntaxe příkazu nepovinné, nemusí být v zápisu příkazu uvedeny. Není-li parametr uveden, je při výpočtu dosazena implicitní (default) hodnota. Implicitní hodnoty nepovinných parametrů jsou pro jednotlivé konkrétní příkazy uvedeny v jejich popisech.
Pro použití implicitně definovaných parametrů platí tato pravidla:
- Jsou-li jako nepovinné označeny poslední parametry příkazu, je možné je v zápisu vynechat bez náhrady.
- Je-li jako nepovinný označen parametr, který není v seznamu parametrů na posledním místě, musí být v případě jeho vynechání uveden jeho oddělovač - čárka.

#### Příklad:

Geometrický příkaz v popisu zapsaný
```
		DM=D29>>S[,[P1][,P2]]

```

může být v programu použit čtyřmi způsoby:
- **DM=D29>>S,P1,P2** — Všechny parametry jsou vyjádřeny explicitně.
- **DM=D29>>S,P1** — Za poslední parametr je dosazena implicitní (default) hodnota.
- **DM=D29>>S,,P2** — Za prostřední parametr je dosazena implicitní hodnota.
- **DM=D29>>S** — Za oba nepovinné parametry jsou dosazeny implicitní hodnoty.
